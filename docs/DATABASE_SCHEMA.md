# HEALTHLOOP 2.0 — MONGODB DATABASE ARCHITECTURE

This document specifies the MongoDB database architecture for HealthLoop 2.0, covering all **18 required collections**, schema definitions, field types, validation rules, indexing strategies, and security isolation policies.

---

## Architecture Principles
1. **User Ownership & Isolation**: Every user-owned document stores an authenticated `user_id`. Queries strictly filter by `user_id` to prevent multi-tenant cross-contamination.
2. **Dual Database Engine**:
   - Production / Atlas: PyMongo with MongoDB replica sets, TTL indexes, and compound indexes.
   - Local / Evaluator Sandbox: Transparent JSON/memory document engine fallback allowing instant evaluation without requiring a local mongod daemon running.
3. **Auditability**: Documents track `created_at` and `updated_at` in ISO 8601 UTC format.

---

## The 18 Required Collections

### 1. `users`
Stores primary authentication identities and password hashes.
- `_id`: String (UUID v4)
- `email`: String (Unique, Indexed)
- `password_hash`: String (scrypt / argon2)
- `username`: String
- `role`: String (`user`, `guest`, `admin`)
- `is_guest`: Boolean
- `created_at`: ISO 8601 UTC String
- `updated_at`: ISO 8601 UTC String
- **Indexes**: `{ "email": 1 }` (unique)

### 2. `user_profiles`
Biometrics, notification preferences, custom habit weights, and wearable tokens.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `age`: Integer
- `gender`: String
- `height_cm`: Float
- `weight_kg`: Float
- `habit_weights`: Object (e.g. `{"exercise": 25, "water": 20, "sleep": 20, ...}`)
- `notification_preferences`: Object (`quiet_hours_enabled`, `quiet_hours_start`, `quiet_hours_end`)
- `wearable_integrations`: Object (`google_health_connect`, `apple_health`, `fitbit`)
- `ai_consent`: Boolean
- **Indexes**: `{ "user_id": 1 }` (unique)

### 3. `habits`
Tracked healthy behaviours and customizable frequency targets.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `title`: String
- `category`: String (`exercise`, `water`, `sleep`, `nutrition`, `meditation`, `general`)
- `target_value`: Float
- `target_unit`: String (`steps`, `ml`, `hours`, `minutes`, `times`)
- `frequency_days`: Array of Integers (`[0, 1, 2, 3, 4, 5, 6]`)
- `current_streak`: Integer
- `best_streak`: Integer
- `archived`: Boolean
- **Indexes**: `{ "user_id": 1, "archived": 1 }`, `{ "user_id": 1, "category": 1 }`

### 4. `habit_logs`
Daily verified completion records.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `habit_id`: String (Indexed)
- `date`: String (Format `YYYY-MM-DD`, Indexed)
- `value`: Float
- `completed`: Boolean
- `logged_via`: String (`manual`, `voice_assistant`, `wearable_sync`)
- `notes`: String
- **Indexes**: `{ "user_id": 1, "habit_id": 1, "date": 1 }` (unique), `{ "user_id": 1, "date": 1 }`

### 5. `goals`
Adaptive goal generator targets and progression levels.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `habit_id`: String (Nullable)
- `title`: String
- `target_value`: Float
- `unit`: String
- `category`: String
- `type`: String (`step_down_recovery`, `gradual_progression`, `custom`)
- `status`: String (`active`, `completed`, `dismissed`)
- **Indexes**: `{ "user_id": 1, "status": 1 }`

### 6. `mood_logs`
Feature 03 emotional wellness check-ins.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `mood`: String (`Happy`, `Neutral`, `Tired`, `Stressed`, `Sad`, `Energetic`)
- `energy_level`: Integer (1 to 5)
- `notes`: String
- `tags`: Array of Strings
- `date`: String (`YYYY-MM-DD`)
- `timestamp`: ISO 8601 UTC String
- **Indexes**: `{ "user_id": 1, "timestamp": -1 }`, `{ "user_id": 1, "date": 1 }`

### 7. `predictions`
Feature 01 AI Habit Interruption probability matrices.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `generated_at`: ISO 8601 UTC String
- `target_date`: String
- `overall_risk_level`: String (`Low`, `Moderate`, `High`)
- `average_consistency`: Float
- `predictions`: Array of Habit Risk Objects
- **Indexes**: `{ "user_id": 1, "generated_at": -1 }`

### 8. `interventions`
JITAI smart moment triggers and adaptive recommendations.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `category`: String (`inactivity`, `hydration`, `habit_salvage`)
- `trigger_reason`: String
- `message`: String
- `action_link`: String
- `dispatched_at`: ISO 8601 UTC String
- **Indexes**: `{ "user_id": 1, "dispatched_at": -1 }`

### 9. `ai_conversations`
History of dialogues with the Gemini AI Coach.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `user_message`: String
- `coach_reply`: String
- `timestamp`: ISO 8601 UTC String
- `context_metrics`: Object
- **Indexes**: `{ "user_id": 1, "timestamp": -1 }`

### 10. `routine_plans`
Circadian daily routine schedules generated by the routine planner.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `title`: String
- `is_active`: Boolean
- `wake_time`: String
- `sleep_time`: String
- `work_hours`: String
- `morning_routine`: Array of Time Slots
- `afternoon_routine`: Array of Time Slots
- `evening_routine`: Array of Time Slots
- `sleep_prep_routine`: Array of Time Slots
- **Indexes**: `{ "user_id": 1, "is_active": 1 }`

### 11. `digital_twins`
Personal Health Digital Twin simulations and baseline states.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `is_simulation`: Boolean
- `baseline_metrics`: Object (Stamina, Recovery, Clarity)
- `inputs`: Object (Walk mins, Sleep target, Extra water)
- `projected_metrics`: Object (Projected Impact Score, Projected Stamina)
- `timeline`: Array of Day Projections
- `simulated_at`: ISO 8601 UTC String
- **Indexes**: `{ "user_id": 1, "simulated_at": -1 }`

### 12. `scores`
Historical Healthy Impact Score daily snapshots.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `date`: String (`YYYY-MM-DD`, Indexed)
- `score`: Float (0 to 100)
- `updated_at`: ISO 8601 UTC String
- **Indexes**: `{ "user_id": 1, "date": 1 }` (unique)

### 13. `garden_items`
Three.js Virtual Habit Garden decorations and unlocked items.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `item_id`: String (`zen_lantern`, `wooden_bench`, `firefly_swarm`, `bird_bath`)
- `unlocked_at`: ISO 8601 UTC String
- **Indexes**: `{ "user_id": 1, "item_id": 1 }` (unique)

### 14. `achievements`
Gamification achievement badges and unlock timestamps.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `code`: String (`FIRST_STEP`, `HYDRATION_HERO`, `STREAK_7`, `RECOVERY_CHAMP`, etc.)
- `unlocked_at`: ISO 8601 UTC String
- **Indexes**: `{ "user_id": 1, "code": 1 }`

### 15. `challenges`
Community and social wellness challenges.
- `_id`: String (UUID v4)
- `title`: String
- `description`: String
- `duration_days`: Integer
- `target_metric`: String
- `target_amount`: Float
- `badge_reward`: String
- **Indexes**: `{ "created_at": -1 }`

### 16. `challenge_participants`
User participation and progress in social challenges.
- `_id`: String (UUID v4)
- `challenge_id`: String (Indexed)
- `user_id`: String (Indexed)
- `joined_at`: ISO 8601 UTC String
- `current_progress`: Float
- `completed`: Boolean
- **Indexes**: `{ "challenge_id": 1, "user_id": 1 }` (unique)

### 17. `wearable_records`
Ingested activity records from Apple Health, Google Health Connect, and CSV/JSON.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `source`: String (`Apple Health`, `Google Health Connect`, `CSV Upload`)
- `type`: String (`steps`, `sleep`, `exercise`, `water`)
- `value`: Float
- `unit`: String
- `date`: String (`YYYY-MM-DD`, Indexed)
- `imported_at`: ISO 8601 UTC String
- `verified`: Boolean
- **Indexes**: `{ "user_id": 1, "date": 1, "type": 1, "source": 1 }` (unique deduplication index)

### 18. `notifications`
Notification stream for JITAI reminders and quiet-hours enforcement.
- `_id`: String (UUID v4)
- `user_id`: String (Indexed)
- `title`: String
- `message`: String
- `category`: String (`hydration`, `movement`, `routine`, `general`)
- `action_link`: String
- `is_read`: Boolean
- `created_at`: ISO 8601 UTC String
- **Indexes**: `{ "user_id": 1, "created_at": -1 }`, `{ "user_id": 1, "is_read": 1 }`
